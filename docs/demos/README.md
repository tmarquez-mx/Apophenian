# Demos de Apophenian

Guía de las seis animaciones incluidas en el [README del proyecto](../../README.md#demos). Cada demo tiene subtítulos en español y una captura fija como alternativa a la animación. Las animaciones avanzan a un ritmo pausado: resaltan cada control antes de usarlo y mantienen las pantallas principales entre 6 y 12 segundos para facilitar su lectura.

## Plantillas

1. Consultar las opciones de tesis, protocolo de investigación y ensayo académico.
2. Elegir **Ensayo académico** para abrir sus apartados.
3. Abrir **Desarrollo argumentativo** y leer su guía de escritura.

[Animación](01-plantillas.gif) · [Captura fija](01-plantillas.png)

## Consulta paralela

1. Abrir un borrador de la introducción.
2. Pulsar **Espejear** y elegir **Marco teórico** en el panel lateral.
3. Pulsar **Abrir este apartado**: el marco teórico pasa al editor y la introducción queda al lado.
4. Elegir **Notas** para consultar las notas personales.
5. Elegir **Materiales de investigación** para consultar las fichas de materiales.

[Animación](02-consulta-paralela.gif) · [Captura fija](02-consulta-paralela.png)

## Grafo Apophenia

1. Abrir la vista **Apophenia** para visualizar apartados y conceptos vinculados.
2. Activar **Mostrar autores** para incorporar las referencias citadas.
3. Pulsar **Revisar la red** para consultar las relaciones y los vínculos que conviene examinar.

Los nodos «Fuente A» y «Fuente B» son referencias ficticias. La red se calcula a partir de los vínculos del proyecto; esta revisión no necesita un modelo de lenguaje.

[Animación](03-apophenia.gif) · [Captura fija](03-apophenia.png)

## Proceso y versiones

1. Consultar las metas y el tiempo por apartado.
2. Abrir el **Tablero** para revisar el avance y la continuidad del trabajo.
3. Abrir **Versiones**, describir el avance y pulsar **Guardar versión**.
4. Volver al **Escritorio** y consultar el **Diario de investigación** en el panel lateral.

La demo guarda una versión; no ejecuta una restauración. Los tiempos y registros de actividad son datos de ejemplo.

[Animación](04-proceso-versiones.gif) · [Captura fija](04-proceso-versiones.png)

## Supervisión de tesis

1. La supervisión abre una copia de revisión con dos apartados compartidos.
2. Escribe una pregunta junto a la introducción y pulsa **Comentar**.
3. Pulsa **Guardar comentarios** para devolverlos a la copia compartida.

La revisión se intercambia mediante un archivo compartido. No es una sesión simultánea en la nube. Se verificó que el texto de la introducción permanece igual después de guardar los comentarios.

[Animación](05-supervision.gif) · [Captura fija](05-supervision.png)

## MentorIA

1. Abrir **MentorIA** desde el apartado.
2. Pulsar **Generar revisión**.
3. Leer los señalamientos y la pregunta de reflexión.

La grabación utiliza el modo de ejemplo de la propia aplicación: **reglas locales, sin un modelo de lenguaje conectado**. No se generaron ni se insertaron respuestas de IA ficticias. Para utilizar un modelo local hay que configurar Ollama o LM Studio. La política de MentorIA es señalar y preguntar; la escritura y las decisiones corresponden a quien investiga.
